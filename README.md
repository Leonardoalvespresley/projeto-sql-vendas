# Projeto SQL: Vendas

Projeto de estudo em SQL com uma tabela de clientes de uma loja fictícia, feito para praticar consultas básicas em banco de dados.

## O que o projeto mostra
- Criação de tabela (`CREATE TABLE`)
- Inserção de dados (`INSERT INTO`)
- Consultas com filtro (`SELECT` e `WHERE`)
- Soma e contagem (`SUM` e `COUNT`)
- Agrupamento de dados (`GROUP BY`)

## Arquivos
- `consultas-basicas.sql`: todos os comandos do projeto, na ordem
